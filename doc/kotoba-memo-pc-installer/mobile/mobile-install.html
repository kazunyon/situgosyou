ことばメモ · スマホ用インストールツール

スマホのホーム画面から
メモを開けるようにします

最初にPC版ツールへ自分のSupabase設定を入力し、公開を済ませてください。スマホも同じ公開先・同じメールアドレスで使うと、メモが同期されます。スマホへのAPIキーの再入力は不要です。

インストールせずに使う

下のボタンでアプリを開き、PCと同じメールアドレスでログインします。ホーム画面への追加は任意です。

ブラウザでアプリを開く

1. 公開先と名前を入力

PC版ツールに入力したユーザー名です。メールアドレスではありません。 iPhoneは追加画面でこの名前を入力できます。Androidの名前は、PC版ツールで公開したアプリ名を使います。 公開したアプリの設定を自動入力します。PCで設定した接続先と一致することを確認してください。 ホーム画面に追加した後、このアドレスへ届く確認コードでログインします。アドレスを公開URLに含めることはありません。

公開先を確認してから、インストールへ進みます。

入力した公開先へ移動

インストールは、アプリと同じ公開先で行います。

自分の公開先で続ける

3. このスマホに追加する

Chromeで開いてください。ボタンが使えるようになったら、タップします。

ボタンが使えない場合
  1. 下の「アプリを開く」をタップします。
  2. Chromeの「︙」メニューをタップします。
  3. 「ホーム画面に追加」または「アプリをインストール」を選び、確認画面で追加します。

すでにインストール済みの場合は、ホーム画面やアプリ一覧から起動します。LINEなどのアプリ内ブラウザでは、メニューからChromeで開き直してください。

Safariで開いてください。以下の順にタップします。

  1. 下の「アプリを開く」をタップします。
  2. Safariのメニューから「共有」（四角に上向きの矢印）をタップします。
  3. 「ホーム画面に追加」をタップします。見つからない場合は共有メニューを下へスクロールします。
  4. 名前の欄に を入力します。
  5. 「Webアプリとして開く」がある場合はオンにし、「追加」をタップします。

貼り付けるときは、名前の欄を長押しして「ペースト」をタップします。

iPhoneはこのページのボタンから直接インストールできないため、Safariの追加画面で操作します。

アプリを開く

4. PCと同じアカウントでログイン

  1. ホーム画面のアイコンから起動します。
  2. メール欄に を入力します。
  3. 「確認コードを送る」をタップし、メールに届いた確認コードを入力してログインします。

PCと異なるメールアドレスでは、別のデータになります。接続先も同じである必要があります。

5. PCとスマホの同期結果を確認

  1. PCで「設定」からカテゴリ「確認用」を追加し、メモ「PCから確認」を保存します。
  2. スマホへカテゴリとメモが自動で表示されることを確認します。
  3. スマホでそのメモの説明を変更し、PCにも反映されることを確認します。
  4. スマホを開き直しても、同じ内容が表示されることを確認します。

通信できない間は、この端末に保存し「未送信」と表示します。次にアプリをオンラインで開くと送信します。変更が競合した場合は、どちらの内容を使うか選びます。古い端末内版のメモは、最初にPCのバックアップから移してください。

まだ公開先がない・確認できない場合

PC版ツールで新しい公開先を作成してください。このスマホ用ツールは、公開済みアプリをホーム画面へ追加するためのものです。スマホからGitHubへの新規公開は行いません。

以前の端末内版は同期できません。更新版PCツールで、自分のSupabaseを指定した新しい公開先を作成し、旧PC版からバックアップを移します。
