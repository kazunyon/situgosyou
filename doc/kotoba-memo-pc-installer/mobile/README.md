# スマートフォン用インストールツール（参考用・Supabase同期版）

このツールは参考用です。[ことばメモ インストール手順書](../../installation_guide.md)を参照してください。[PC参考ツールのREADMEへ戻る](../README.md)。

## 追加操作を減らす使い方

公開済みアプリのHTTPS URLをSafariまたはChromeで開き、PCと同じメールでログインすれば使えます。ホーム画面へのPWA追加は任意です。スマホ用ページにも「ブラウザでアプリを開く」を追加しました。修正版アプリは6～10桁の確認コードに対応します。スマホにZIPや追加ソフトを入れる必要はありません。

PC版で公開した「ことばメモ」を、iPhoneまたはAndroidのホーム画面へ追加するための案内ツールです。PCと同じSupabaseプロジェクト・同じメールアドレスで使い、メモとカテゴリを共有します。

## 最初に必要なもの

- iPhoneとSafari、またはAndroidとChrome。
- インターネット接続と、ログイン用メールを読める環境。
- 改訂版PCインストールツールで公開したスマホ用URL。
- 公開先のGitHubユーザー名、リポジトリ名、表示したい名前。
- PCで設定したSupabaseのProject URL。
- PCと同じログイン用メールアドレス。

Supabaseのプロジェクト作成、SQLの実行、メール認証の準備は、先にPCで行います。一般の利用者へメールを送る場合はカスタムSMTPも必要です。

## 入力して進める

1. PCツールの完了画面に表示されたスマホ用URLを開きます。
2. GitHubユーザー名、リポジトリ名、アプリ名を確認・入力します。
3. SupabaseのProject URLがPCと同じことを確認します。
4. PCと同じログイン用メールアドレスを入力します。
5. 接続先の確認を進め、表示されたインストール案内に沿ってホーム画面へ追加します。

公開したアプリにはPCで入力した公開用キーが組み込まれているため、スマホでキーを入れ直す必要はありません。Project URL欄は接続先の確認用です。この欄でアプリの保存先を変更することはできません。

貼り付けは入力欄を長押しし、「ペースト」または「貼り付け」をタップします。左手だけで順番に操作できます。

## iPhone 14の場合

1. スマホ用URLをSafariで開きます。
2. 入力・接続先確認を終え、アプリをSafariで開きます。
3. 「共有」をタップします。
4. 「ホーム画面に追加」をタップします。見つからない場合は共有メニューを下へスクロールします。
5. 表示名を確認し、「追加」をタップします。「Webアプリとして開く」があれば有効にします。
6. ホーム画面のアイコンをタップします。
7. PCと同じメールアドレスを入力し、メールに届いた確認コード（6～10桁）でログインします。

Safariでログイン済みでも、ホーム画面から開いたアプリで再度ログインが必要になる場合があります。端末ごとに届いた確認コードを使ってください。

## Androidの場合

案内のインストールボタンをタップします。ボタンが使えない場合はアプリをChromeで開き、メニューから「アプリをインストール」または「ホーム画面に追加」を選びます。インストール画面の名前は、公開時のアプリ名に従うことがあります。

## 同期の確認

1. PCでカテゴリとメモを1件登録します。
2. iPhoneまたはAndroidで同じメモが表示されることを確認します。
3. スマホでメモを変更します。
4. PCで変更が反映されたことを確認します。

アプリを開いて通信できるときに同期します。オフラインの変更は端末に保存して後から送信します。未送信の表示が消えるまで確認してください。別端末と同じメモを同時に変更した場合は、競合の案内で採用する内容を選びます。

詳しい準備・移行・確認手順は、PCツールに同梱された `installation_guide.md` を参照してください。

## ZIPの位置付け

このZIPは案内ページの配布・開発用です。スマホでZIPを開いたり、端末内のHTMLを開いたりするだけではPWAをインストールできません。通常はPC版が公開したHTTPSのスマホ用URLを使います。

以前の端末内保存版のメモは自動移行しません。PCでバックアップを取得し、新しい同期版へ復元してから確認します。

## 公開用の設定ファイル

公開済みの `installer-config.json` は `schemaVersion: 2`、`storageMode: supabase` と、リポジトリ名・アプリ名・Project URLを持ちます。公開用キーやメールアドレスはこのファイルに保存しません。同梱の未設定サンプルは接続先確認に合格しません。

メールアドレスはアプリへの移動URLに含めません。同じ公開先のブラウザ内でログイン入力を補助しますが、ホーム画面から開くと再入力が必要になる場合があります。

## 開発時の確認

`tests/mobile-installer.test.cjs` で入力検証、接続先照合、移動先URL、メールアドレスの扱い、インストール案内の模擬確認を行います。PC側の生成ビルドでも公開ファイルとPWAの生成を確認します。

実際のSupabaseでのメール送信と、実機スマートフォンでのインストール・双方向同期は、導入先で別途確認してください。
