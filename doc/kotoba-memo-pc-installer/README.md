# ことばメモ：PCインストールツール（参考用・Supabase同期版）

Windowsの画面から、自分のGitHubへPWAを公開します。メモとカテゴリは、導入する人自身のSupabaseへ保存し、PCとスマートフォンで共有します。

## このフォルダーの位置付け

このツールは **参考用** です。導入・設定・結果確認は [ことばメモ インストール手順書](../installation_guide.md) を参照してください。ツールの利用は任意です。一般利用者は公開URLを開いてログインできます。

指定された提供フォルダーから必要なファイルを収録しました。提供フォルダーに起動用ファイルがなかったため、開発用ソースのStart-Installer.cmdを補っています。

## 収録版の内容

- まず同梱の **Setup.html** を開きます。追加ソフトなしで、ブラウザからSupabase・Gmailの準備を進められます。
- Supabase管理画面のURLを貼り付けても、接続用URLへ変換します。
- 生成アプリは6～10桁のメール確認コードを受け付け、8桁に対応します。
- 検証できた入力はこのPCだけに保存し、次回復元します。保存対象はGitHub名・リポジトリ名・アプリ名・Project URL・公開用キーです。SMTPパスワードやGoogleアプリパスワードは保存しません。
- 公開後は **「3. ブラウザでアプリを開く（インストール不要）」** から使えます。PWA追加は任意です。
- 一般利用者は公開URLを開いてログインするだけです。PCツールやGitHub CLIの導入は公開を準備する人だけに必要です。
- 既存公開先の再実行は公開再開用です。修正したテンプレートで既存アプリを更新する操作ではありません。

## 最初に必要なもの

- Windows 10または11、EdgeまたはChrome、インターネット接続。
- 自分のGitHubアカウント。
- 自分で新しく作る、このアプリ専用のSupabaseプロジェクト。
- そのプロジェクトのProject URLと公開用キー（Publishable key、または従来のanon key）。
- PCとスマホで使う同じログイン用メールアドレス。
- 確認コードのメールを届けるための設定。一般の利用者への配布には、SupabaseでカスタムSMTPを設定します。

Git・Node.jsを自分でインストールする必要はありません。必要なGitHub CLIは公式配布元から取得し、チェックサムを確認します。

## 入力する項目

| 項目 | 入力する内容 |
|---|---|
| GitHubユーザー名 | 自分のGitHubの名前 |
| 公開用リポジトリ名 | 今回新しく作る公開先の名前 |
| アプリ名 | ホーム画面などに表示する名前 |
| Project URL | 自分のSupabaseプロジェクトのURL |
| 公開用キー | 自分のプロジェクトのPublishable key、またはanon key |

公開用キーはアプリへ組み込まれ、利用者から見える情報です。`service_role`、`sb_secret_...`、データベースのパスワードは入力しません。メモを保護するRLSは、準備用SQLで設定します。

## 操作の順番

1. ZIPを右クリックし、「すべて展開」をクリックします。
2. 展開したフォルダーの `Start-Installer.cmd` を開きます。
3. GitHubユーザー名、リポジトリ名、アプリ名を入力します。
4. 自分のSupabaseのProject URLと公開用キーを入力します。貼り付けは入力欄を右クリックして行えます。
5. ツールの「準備用SQLをコピー」をクリックします。
6. 自分のSupabaseのSQL Editorを開き、新しいクエリに貼り付けて「Run」をクリックします。
7. Supabaseのメール認証とメールテンプレートを設定します。必要に応じてカスタムSMTPも設定します。
8. 自分のプロジェクトの準備が済んだことを確認し、チェック欄をクリックします。
9. GitHub認証の案内に沿って、自分のアカウントでログインします。
10. 公開を実行し、「3. ブラウザでアプリを開く（インストール不要）」をクリックします。PWA追加は希望する場合に行います。
11. アプリでメールアドレスを入力し、メールの確認コード（6～10桁）でログインします。
12. 完了画面のスマホ用URLをiPhoneまたはAndroidで開き、同じメールアドレスでログインします。

画面名、Supabaseの準備、メール設定、iPhone 14の操作、双方向同期の確認は、[ことばメモ インストール手順書](../installation_guide.md)に記載しています。先にこちらを読んで準備してください。

## 以前のメモを引き継ぐ場合

以前の端末内保存版でバックアップをダウンロードしておきます。新しい同期版で同じメールアドレスでログインし、共有先が空の状態で、そのバックアップを復元します。復元後、スマホにも表示されることを確認します。詳しい順番は手順書を参照してください。

以前の端末内保存版を公開したリポジトリは、この改訂版ではそのまま更新しません。新しいリポジトリ名を入力して導入してください。

## 再実行と保存する情報

- 途中で止まった場合は、同じGitHub名・リポジトリ名・アプリ名・Supabase設定で再実行します。
- 公開先のID、作成時点のコミットなどを照合し、無関係なリポジトリへの上書きを拒否します。
- 再実行確認用のSupabase設定はハッシュとして保存します。設定が変わった場合は、新しい公開先で導入します。
- 作者のSupabase設定やGitHubのSecretsは引き継ぎません。
- `app-template` と `mobile` は必要な同梱フォルダーです。削除せず、そのまま使ってください。
- スマホ用ツールの説明は [mobile/README](mobile/README.md) にあります。

開発用のテスト・配布作成スクリプトはこの参考フォルダーには同梱していません。[開発用ソースの説明](../../installer/pc/README.md)を参照してください。

## 開発時の確認（開発用ソース側）

- `tests/Installer.Tests.ps1`：入力検証、生成内容、再実行、GitHub操作の模擬確認。
- `tests/GeneratedBuild.Tests.ps1`：生成アプリのTypeScript・PWAビルド、公開用ファイルの確認。
- `tests/CloudSync.Tests.cjs`：オフライン保存、再送、利用者の分離、競合処理の模擬確認。
- `Build-Package.ps1`：PC配布用ZIPの作成。

これらの確認は、実際のSupabaseでのSQL実行、メール送信、iPhoneでのインストール・同期の成功を保証するものではありません。導入先で手順書の確認項目を実施してください。
