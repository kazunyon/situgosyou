# ことばメモ

失語症のある方が、思い出したい「ことば」や説明を、必要なときにすぐ確認するための個人用PWAです。
まさに「失語症あるある」で、「あれ、なんだっけ」を、読みを記憶することで、すかさずサポートします。PCの端っこにいつもいることで、安心です。また、スマホ対応なので、外出先でも大丈夫です。Supabaseを設定すると、オンライン時にPCとスマートフォンのデータを同期できます。データは［日常用］と［PC/Linux用］の大分類に分けて管理します。

日常用では、表示番号とカテゴリを別々に管理し、すべて／マーク表示、タイトル色、カテゴリで絞り込めます。PC/Linux用では、1つの操作項目に画像＋説明の手順を最大10件まで登録できます。

Supabaseを設定すると、同じメールアドレスでログインしたPCとスマートフォンで、両方のデータを利用できます。

公開先：<https://kazunyon.github.io/situgosyou/>

インストール・設定手順：[ことばメモ インストール手順書](doc/installation_guide.md)

参考資料：[PCインストールツール（参考用）](doc/kotoba-memo-pc-installer/README.md)。公開準備を補助するツールです。利用は任意で、導入方法・必要な設定・結果の確認は上の手順書をご覧ください。

## 主な機能

- メモの登録・編集・削除
- ［日常用］と［PC/Linux用］の大分類切り替え
- PC/Linux用では「操作項目を追加」から、操作項目の名前と画像＋説明の手順を最大10件まで登録
- Snipping Toolで切り取った画像を、ファイル保存せずクリップボードから直接貼り付け
- 各メモの表示番号とカテゴリを独立して管理
- 表示番号を保ったまま、各メモの「並べ替え」から一覧の順番を変更
- 最大10件まで追加・名称変更できるカテゴリマスター
- タイトルと意味・説明の検索
- 表示時のMarkdown記法（太字・斜体・リンク・見出し・箇条書き・取り消し線）
- 大切なメモへの星マーク
- 日常用タイトルの色分け（黒・赤・青・緑・灰色）と色別抽出
- 日本語の音声入力（対応ブラウザのみ）
- 「意味・説明」ボタンでWikipediaから約500文字の説明を取得
- 日常用メモの「ことばを聞く」「説明を聞く」と、ふつう／ゆっくりの読み上げ
- Supabaseを使ったPC・スマートフォン間の同期
- メールに届く6桁の確認コードによるパスワード不要ログイン
- メモとカテゴリをJSONファイルへバックアップ・復元
- RLS（行レベルセキュリティ）による利用者ごとのデータ分離

## PC/Linux用の操作手順を登録する

1. **PC/Linux用**を開き、**操作項目を追加**を押します。
2. 表示番号を確認し、**操作項目の名前**に「ファイルをコピーする」など、覚えておきたい操作の名前を入力します。
3. **手順**ごとに、その画面のスクリーンショットや写真を **画像を選ぶ（任意）** から選びます。Snipping Toolで切り取った画像は、**Snipping Toolから貼り付け**でも追加できます。画像なしでも登録できます。
4. **説明（必須）**に、その画面で何をするか入力します。手順は **次の手順を追加** から増やせ、1つの操作項目に最大10件まで登録できます。
5. **保存**を押すと、操作項目が一覧に登録されます。

## ネットから「意味・説明」を入力する

1. **日常用**で **新しく書く**、またはメモの編集画面を開きます。
2. タイトルに、例えば `ミュージシャン` と入力します。
3. **意味・説明** ボタンを押します。
4. 日本語Wikipediaから取得した説明が入力欄へ入ります。内容を確認し、必要に応じて直して **保存** を押します。

説明本文は約500文字を目安に、400〜600文字の範囲では文末を優先して抜粋します。元の記事が短い場合は短いまま、適切な文末がない場合は500文字で省略します。出典URLとライセンス表記は本文に加えて保存します。`ミュージシャン` → `音楽家` のようなWikipediaの転送にも対応します。

入力済みの説明は置き換え前に確認します。該当記事がない場合、同じ名前の項目が複数ある場合、通信エラーや15秒のタイムアウトでは説明を変更しません。取得中にタイトルや説明を編集したり、編集画面を閉じたりすると取得を中止します。

ボタンを押したときだけ、タイトルを日本語Wikipediaへ送信します。メモの説明やログイン情報は送信しません。インターネット接続が必要ですが、追加のAPIキーやDB変更は不要です。一般のWeb検索やAIによる文章生成ではなく、Wikipediaの記事本文の抜粋・整形です。

技術資料：[MediaWiki TextExtracts](https://www.mediawiki.org/wiki/Extension:TextExtracts)、[CORS](https://www.mediawiki.org/wiki/API:Cross-site_requests)。取得文の出典・[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)表記を含めてバックアップ・同期できます。

## ことば・説明を聞く

1. **日常用**のメモを開きます。
2. タイトルの下の **ことばを聞く** でタイトルを、説明欄の下の **説明を聞く** で説明本文を読み上げます。編集中は、その時点の入力内容を読みます。
3. **読む速さ** の **ふつう**（1.0）／**ゆっくり**（0.7）で速さを選びます。選んだ速さは、この端末・ブラウザに保存され、次回も使われます。
4. 再生中のボタンは **止める** に変わります。押すと停止します。別の読み上げボタンを押すと切り替わり、再生中に速さを変えると最初から読み直します。

説明の出典・参考情報・ライセンスの行とURLは読みません。保存済みの文章や出典は変更しません。長い説明は短い区切りで順番に読みます。入力内容を変更したとき、編集画面を閉じたとき、別タブへ移ったとき、音声入力を開始するときは停止します。

ブラウザのWeb Speech APIと端末で利用できる日本語音声を使います。追加のAPIキーは不要です。声・発音・速度の聞こえ方は端末によって異なり、音声によっては通信が必要です。非対応ブラウザでは読み上げボタンを無効にして案内します。音が出ない場合は端末の音量と音声設定を確認してください。速さの設定はメモの同期・バックアップの対象には含みません。

## 保存と同期

Supabaseを設定すると、オンライン時に同じメールアドレスでログインした端末間でデータを同期できます。オフライン中の変更は端末に保留されず、オンライン復帰後にも自動送信されません。重要なデータは定期的にバックアップしてください。保存方法や設定手順は[インストール手順書](doc/installation_guide.md)をご覧ください。
